# Last Asylum Compendium

This repository contains the source code for the S78 Last Asylum Guide site, built using Jekyll.

## Repository Setup & Local Development

This site is built using Jekyll and optimized for deployment via GitHub Pages.

1. **Install Dependencies:** `bundle install`
2. **Run Local Server:** `bundle exec jekyll serve`
3. **Local URL:** Open [http://localhost:4000](http://localhost:4000) in your browser.

## Site Architecture & Components

* **`/guides/`**: Directory for all core strategy documentation.
* **`markdown.md`**: Contains the custom `split-view` template for documenting formatting syntax.
